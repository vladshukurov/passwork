# Система стилей Пассворка

Рабочие токены находятся в [`dist/passwork-tokens.css`](../dist/passwork-tokens.css). Они подключаются до стилей компонентов. Отдельный файл `dist/code/design-tokens.css` содержит параметры унаследованного демо Attio; для новых секций используйте `--pw-*`.

| Группа | Токены | Где применяются |
| --- | --- | --- |
| Цвет | `--pw-page`, `--pw-surface`, `--pw-text`, `--pw-text-muted`, `--pw-text-secondary`, `--pw-border`, `--pw-accent` | Фоны, текст, разделители и акценты |
| Типографика | `--pw-font`, `--pw-font-ui`, `--pw-heading-*`, `--pw-lead-*`, `--pw-card-*` | Общие вводные блоки, карточки, кнопки |
| Отступы | `--pw-space-*`, `--pw-section-*`, `--pw-card-x`, `--pw-card-bottom` | Повторяющиеся промежутки и адаптивная компоновка |
| Форма | `--pw-radius-control`, `--pw-radius-window`, `--pw-radius-card`, `--pw-radius-dialog` | Кнопки, окна, карточки, диалоги |
| Движение | `--pw-duration-*`, `--pw-ease-ui`, [`dist/site-motion-tokens.js`](../dist/site-motion-tokens.js) | CSS состояния и GSAP сцены |

Вводные блоки «Сертификация» и «Российское решение» используют общий `.section-intro`: две колонки на широком экране и одну на телефоне. Их заголовки, лиды, отступы и кнопки получают общие значения; особенности блока безопасности остаются в `dist/security-switcher.css`.

У `.button` один радиус и высота для обычных CTA. `.button-small` предназначена для компактных мест, а `.button-dark` и `.button-outline` меняют палитру. Состояния hover, active, focus-visible и disabled заданы в `dist/attio-buttons.css`.

На ширине до 1280 px четыре карточки сертификации переходят в две колонки; до 720 px — в одну. Анимация SVG включается только на устройствах с точным указателем и при разрешённом движении. При `prefers-reduced-motion: reduce` композиция остаётся статичной.

Изображения и градиент Hero — отдельные дизайн-ассеты, поэтому их цвета не заменяются сплошными CSS-заливками. Перед правкой общего токена проверяйте Hero, оба вводных блока, карточки сертификации и мобильную ширину 390 px.

Футер и FAQ пока не включены в страницу. Заготовка футера сохранена в `source/site-footer.html` и `dist/site-footer.css`.

Логотип имеет два самостоятельных SVG: `logo-light.svg` — чёрная надпись и синяя иконка с белым ключом для светлой поверхности, `logo-dark.svg` — белый с прозрачным вырезом ключа для тёмной. Состояние шапки переключает их видимость; цветовые фильтры к логотипу не применяются.

В четырёх иллюстрациях передние контуры используют `--pw-art-front`, остальные — `--pw-art-line`. GSAP плавно окрашивает выбранные грани в `--pw-art-active` одновременно с небольшим движением внутренних слоёв; указатель не смещает всю композицию. Вне экрана движение сбрасывается.
