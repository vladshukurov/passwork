# Дизайн-система сайта

Сайт и Figma-файл говорят на одном языке: у каждой переменной Figma есть CSS-переменная
с тем же именем. Значение меняется в одном месте, а дизайн и код сверяются по имени.

## Слои токенов

| Файл | Что внутри |
| --- | --- |
| `src/styles/ds-tokens.css` | **Источник правды.** Токены с именами переменных Figma: цвета (`--color-*`), отступы (`--space-*`), радиусы (`--radius-*`), кнопки (`--button-*`), типографика (`--type-*`). Здесь же тёмный режим. |
| `src/styles/passwork-tokens.css` | Рабочие псевдонимы сайта `--pw-*` и ритм `--s-*`. Цвета ссылаются на `ds-tokens.css`. Здесь же токены движения `--pw-motion-*`. |
| `src/styles/tokens.css`, `typography.css`, `rhythm.css`, `states.css` | Общие правила: шкала текста, вертикальный ритм, hover и фокус. |
| `src/styles/theme-dark.css` | Тёмная тема (превью в dev, в продакшен не включена). |

Правило имени: `группа/имя` в Figma → `--color-группа-имя` в CSS. Например,
`text/primary` → `--color-text-primary`, `button/dark/bg-hover` → `--color-button-dark-bg-hover`.

## Цвет

Коллекция Figma **Color** с режимами Light и Dark соответствует блоку `:root` и блоку
`:is([data-theme="dark"], .theme-dark)` в `ds-tokens.css`.

- `text/*` — текст: primary, secondary, tertiary (AA на белом и на фоне страницы), on-brand для синих сцен.
- `surface/*` — поверхности: page `#FAFAFB`, default (белый), subtle, brand (синие сцены), inverse (тёмные полосы).
- `border/*` — волосяные линии и фокус.
- `button/{default,dark,ghost,disabled}/*` — все состояния кнопок.
- `illustration/*` — линии и грани изометрических иллюстраций.
- `product/*` — цвета внутри макетов интерфейса Пассворка (демо и скриншоты).

Тёмные полосы на странице («Доверие», «Кейсы», «Цены», футер) в Figma — это тот же набор
токенов в режиме Dark: режим коллекции Color задан на фрейме секции. В коде режим Dark
включает класс `.theme-dark` на секции (так сделаны «Кейсы»). «Доверие», «Цены» и футер
пока оформлены своими правилами в `figma-2026.css` с теми же значениями. Новые тёмные
блоки делайте через `.theme-dark`.

Коллекция **Primitives** в Figma скрыта: это палитра, из которой берутся значения, в код
она не переносится.

## Типографика

Шрифт — **Museo Sans Cyrl 500**: заголовки и текст, один вес. Код в демо — JetBrains Mono.
Файлы шрифтов — `public/passwork-assets/*.otf`.

Роли из коллекции Figma **Typography** имеют режимы 1920 и 1440. В CSS им соответствуют
`--type-<роль>-size` и `--type-<роль>-leading`. Размер плавно меняется между этими
ширинами через `clamp()`.

| Роль | 1920 | 1440 | Где |
| --- | --- | --- | --- |
| Display | 64/64 | 48/48 | заголовок первого экрана |
| Heading 1 | 48/52 | 36/40 | заголовки секций |
| Heading 2 | 44/47 | 34/37 | крупные утверждения |
| Heading 3 | 34/39 | 28/32 | результаты кейсов, главы |
| Title | 20/26 | 20/26 | заголовки карточек |
| Title S | 21/29 | 18/25 | названия тарифов, историй |
| Body L | 20/26 | 16/24 | лиды |
| Body | 16/22 | 16/22 | основной текст |
| Body M | 16/24 | 14/22 | описания в интро |
| Body S | 15/22 | 15/22 | описания карточек |
| Label L / Label | 16/20, 15/20 | 16/20, 15/20 | кнопки, вкладки, навигация |
| Caption L / Caption / Small | 14/20, 13/18, 12/18 | то же | подписи, метки |

Стили `UI/*` в Figma (9–18 px) нужны только для текста внутри макетов продукта.

## Отступы и сетка

Коллекция **Layout** (режимы 1920 / 1440):

| Токен Figma | CSS | Значение на сайте |
| --- | --- | --- |
| `page/grid-width` | `--page-grid-width` | 1524 px — ширина контентной сетки |
| `section/padding-top`, `padding-bottom` | `--space-section-top`, `-bottom` | 72–120 px и 40–64 px |
| `section/inset` | `--space-section-inset` | 20–56 px — внутренний отступ блоков |
| `section/intro-gap`, `heading-gap` | `--space-section-intro-gap`, `-heading-gap` | 28 px, 20 px |
| `card/padding`, `padding-lg`, `gap` | `--space-card`, `--space-card-lg`, `--space-card-gap` | 20–32 px, 24–44 px, 8 px |
| `radius/control`, `control-sm`, `window`, `card`, `dialog`, `pill` | `--radius-*` | 10, 8, 8, 12, 16, 99 px |
| `button/height/{s,m,l}` | `--button-height-*` | 36, 42, 48 px |

В Figma у `section/padding-top` 152 px на 1920, на сайте — 120 px. Так решили
сознательно. Значение Figma записано комментарием в `ds-tokens.css`.

Страница собрана на сетке шириной 1524 px с волосяными вертикальными линиями по краям.
Соседние блоки разделяет `SectionDivider` (`components/Decor.jsx`).

## Компоненты

| Компонент | Код | Figma |
| --- | --- | --- |
| Кнопка | `components/Button.jsx`: `variant` = default / dark / ghost / outline, `dialog` — какое окно открыть | `Button` (Variant × Size × State) |
| Интро секции | `components/SectionIntro.jsx` | `Section intro` |
| Иллюстрация | `components/IllustrationArt.jsx`: `name` = имя SVG | `Illustration/*` |
| Окно заявки | `components/ContactDialog.jsx` | — |
| Карточки, вкладки, тарифы, кейсы, отзывы | разметка в `sections/*` | `Card/*`, `Tab/*`, `Pricing plan`, `Card/Case`, `Card/Review`… |

Новые блоки собирайте из этих частей и токенов. Если нужен новый вариант кнопки, добавьте
его в `Button.jsx` и `attio-buttons.css`, а не отдельный стиль в секции.

## Иллюстрации

Восемь изометрических SVG (`src/art/illustrations/`) нарисованы в одном языке:
- чистая линия без постамента;
- грани цвета страницы, правые грани чуть темнее;
- серый контур в покое и синий при наведении;
- одинаковая визуальная масса у всех сцен.

Цвета задаёт CSS через `data-face`, поэтому в самих файлах цвета не важны. Механика hover
описана в [motion.md](motion.md#иллюстрации-сборка-и-hover).

Принципы, на которых сошлись в работе:
- никаких мелких украшений на поверхностях;
- без теней и цветных ореолов;
- движение физически правдоподобно: выезжает ящик, а не весь шкаф;
- сцены не повторяют друг друга.

## Тёмная тема

Готова как превью. В `npm run dev` её включает переключатель в правом нижнем углу или
параметр `?theme=dark`. Цвета задают режим Dark в `ds-tokens.css` и `theme-dark.css`.
Чтобы включить тёмную тему в продакшене, понадобится переключатель в интерфейсе: сейчас
он есть только в dev (`src/dev/ThemeToggle.jsx`).
