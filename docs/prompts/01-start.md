# Старт работы, архитектура, токены

## Как было

Сначала сайт был статической страницей. 24 сентября его 1:1 перенесли на React + Vite,
27 сентября провели рефакторинг: секции стали React-компонентами, GSAP — пакетом из npm,
мёртвый код удалён. Токены дизайна потом свели с переменными Figma.
