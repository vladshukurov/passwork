# Figma: перенос сайта и дизайн-система

## Как было

28–29 сентября сайт перенесли в Figma.

Как это сделали:
1. Агент обошёл DOM живой страницы и вывел из него auto layout.
2. Собрал компоненты и разложил страницу на 1920.

Дальше:
- типографику свели к 15 ролям сайта и 10 ролям UI;
- переменные разложили на коллекции Primitives / Color (Light, Dark) / Layout /
  Typography (1920, 1440);
- скриншоты продукта взяли из публичной документации passwork.ru.

5 октября всё это собрали в UI kit на странице «UI Kit» (см. [../figma.md](../figma.md)).
