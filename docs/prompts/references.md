# Референсы

Список, который заказчик дал в начале работы. Ориентироваться на него стоит по общему
ощущению и визуальному языку, а не копировать:

- [attio.com](https://attio.com/) — основной ориентир внутри команды заказчика; оттуда же
  приём «закреплённый список слева, контент скроллится справа»
  ([страница Call intelligence](https://attio.com/platform/call-intelligence))
- [linear.app](https://linear.app/) — линейные иллюстрации, где линии строят форму
- [supabase.com](https://supabase.com/), [cal.com](https://cal.com/) — простые SaaS-иллюстрации
- [clerk.com](https://clerk.com/), [plane.so](https://plane.so/), [stripe.com](https://stripe.com/),
  [gitbook.com](https://www.gitbook.com/), [steep.app](https://steep.app/),
  [clutch.security](https://www.clutch.security/)
- [firecrawl.dev/pricing](https://www.firecrawl.dev/pricing) — один ползунок размера команды,
  карточки тарифов пересчитываются

Контент для блоков брали с [passwork.ru](https://passwork.ru/) и
[passwork.pro](https://passwork.pro/) (логотипы клиентов), скриншоты продукта — из
публичной документации passwork.ru.
