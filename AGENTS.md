# Контекст проекта для ИИ-агентов

Этот файл автоматически читают Codex, Cursor и другие агенты. Claude Code читает его через
`CLAUDE.md`. Здесь собраны правила, которые иначе пришлось бы повторять в каждом промте.

## Что это

Маркетинговый одностраничный сайт Пассворка — корпоративного менеджера паролей.
Язык интерфейса — русский. Стек:
- React 19 + Vite 7, без роутера и без бэкенда;
- анимации — GSAP 3 + ScrollTrigger из npm;
- живые демо интерфейса — TypeScript в `src/dashboards`;
- иконки — SVG и `lucide-react`.

## Команды

- `npm ci` — установка зависимостей.
- `npm run dev` — сервер на http://127.0.0.1:8773.
- `npm test` — юнит-проверки: логика скролла и целостность SVG-иллюстраций.
- `npm run build` — сборка в `dist/`.
- `npm run smoke` — Playwright-проверка; нужен запущенный dev-сервер.

Перед тем как сказать «готово», запусти `npm test` и `npm run build`. Если менялось
поведение, запусти и `npm run smoke`.

## Где что лежит

- `src/App.jsx` — порядок секций.
- `src/sections/*.jsx` — по файлу на блок страницы. Тексты лежат прямо в них.
- `src/components/` — `Button`, `SectionIntro`, `ContactDialog`, `IllustrationArt`, `Decor`.
- `src/motion/` — вся GSAP-логика. Токены — `site-motion-tokens.js`.
- `src/dashboards/hero/` — живое окно продукта в первом экране; `src/dashboards/teams/` —
  демо команд.
- `src/art/illustrations/*.svg` — 8 изометрических иллюстраций.
- `src/styles/ds-tokens.css` — токены с именами переменных Figma, источник правды для
  цвета, отступов и типографики.
- `public/passwork-assets/` — все картинки, шрифты и логотипы.
- `docs/motion.md` — карта всех анимаций. `docs/design-system.md` — токены и компоненты.

## Правила кода

- Стиль окружающего кода: функциональные компоненты, короткие модули, комментарии только
  там, где неочевидно «почему».
- Цвета, отступы, радиусы и шрифты — только через токены (`--color-*`, `--space-*`,
  `--radius-*`, `--type-*` или `--pw-*`). Hex-значения в новых правилах не пишем.
- Длительности и кривые — только из `siteMotion` / `--pw-motion-*`. Новых чисел для
  таймингов не вводим.
- Текст пропускаем через `tidyCopy()`: он склеивает предлоги с последующим словом.
- Порядок импорта CSS в `src/main.jsx` важен. Новые стили — в конец или в файл секции.
- Новые картинки — WebP в размере показа. Внешние CDN, шрифты, скрипты и запросы к API
  запрещены: их блокирует CSP в `vercel.json`, и сайт должен работать автономно.
- У каждого GSAP-контроллера есть функция очистки (`useController` /
  `useEffect` return). Для медиа-условий используй `gsap.matchMedia()`.
- Доступность: вкладки — `role="tablist"` и стрелки на клавиатуре; у всего интерактивного
  есть фокус. При `prefers-reduced-motion: reduce` контент статичен и виден.

## Правила дизайна (выработаны с заказчиком)

- Визуальный язык — спокойный SaaS: тонкие волосяные линии сетки, фон страницы `#FAFAFB`,
  синие сцены с точечным паттерном, тёмные полосы для «Доверия», «Кейсов», «Цен» и футера.
- Одинаковые по смыслу блоки свёрстаны одинаково: интро секции — всегда `SectionIntro`,
  отступы — из токенов. Не изобретай новый вариант для похожего блока.
- Без теней-«подсветок», цветных ореолов, свечения и грязных градиентов. Кнопки при hover
  не поднимаются, только меняют цвет за 160–280 мс.
- Hover начинается сразу, переходы мягкие, без «прыжков». Один главный жест на переход.
- Иллюстрации — чистая линия, грани цвета страницы, синий только при hover, без
  постаментов и мелких деталей. Движение физически правдоподобно.
- Живое окно в первом экране: весь сценарий — 15–20 секунд, не длиннее.
- Тексты — конкретные, без канцелярита и без маркетинговых штампов. Не выдумывай контент,
  которого нет на passwork.ru или в макете.

## Как проверять визуально

Открой `npm run dev` и посмотри на ширинах 1440, 1100, 800 и 390 px. Проверь:
- прямой и обратный скролл через первый экран, «Возможности» и «Безопасность»;
- быстрые переключения вкладок;
- включённое в системе «Уменьшить движение».

Сравни с Figma-файлом (`docs/figma.md`). Если правка затрагивает несколько блоков,
проверь их все, а не только тот, о котором шла речь.
